# PDF→Markdown 踩坑与对策（详细版）

本文件补充 SKILL.md 的细节，按"踩坑→根因→对策"组织。

## 1. 用脚本自动 reflow（最严重）
- **现象**：Figure 1 的描述文字被正则误判成公式，塞进 `\[...\]`；ALL CAPS 章节标题（如 `1 INTRODUCTION`）没转成 `##`；表格被压成"每个单元格一行"的扁平文本。
- **根因**：自动 reflow 无法区分正文/公式/标题/表格的语义边界；硬换行合并会把表格行也连成乱码。
- **对策**：排版全程手工。文本来源可用 `get_text("text"/"dict")` 取出，但合并段落、定标题层级、转公式/表格必须由人逐段写。脚本只做"像素裁剪"。

## 2. 绘图簇聚类裁图不可靠
- **现象**：漏掉某些图（如线图 Figure 2 没被裁出）；散点图过裁成整列（935×1733，含大量上方文字）。
- **根因**：`page.get_drawings()` 的聚类依赖图形分布，线图可能分散被过滤；图区与上方文字无边界时，"从上一个文字块到图注"会吞掉整列。
- **对策**：用**图注锚定裁剪**——先定位 `Figure N:` 图注 bbox，裁其正上方区域。过裁时用**二次限定**：在该列图注上方取 `get_drawings()` 与 image block 的并集 bbox 再裁。整页渲染作回退。

## 3. assets 路径含空格/括号
- **现象**：原始 assets 文件夹名带 ` (1)`，导致 `![alt](path (1)/fig.png)` 被路径中的 `)` 截断，图片渲染失败。
- **根因**：Markdown 行内图片 `![](...)` 的目标 URL 不能含未转义的空格/括号。
- **对策**：把 assets 文件夹重命名为无空格/括号的简洁名（如 `sc_assets/`、`lats_assets/`、`paper_assets/`）。图引用用相对该 md 文件位置的简洁相对路径。

## 4. 图注正则误匹配正文引用
- **现象**：正文里"Figure 1 illustrates the self-consistency method..."被当成图注，触发图片注入。
- **根因**：`Figure\s+\d+` 同时匹配图注和正文引用。
- **对策**：图注正则用 `^Figure\s+\d+\s*[:.]`（图注紧接冒号/句点，且通常是块首）。占位符位置最终仍由人阅读决定，不靠正则自动注入。

## 5. 双栏论文裁图未按列
- **现象**：单列图被裁成跨双列（含隔壁栏文字），或跨双列图被裁成单列（缺一半）。
- **根因**：假设了单栏布局。
- **对策**：按图注宽度判断列边界——图注宽 > 0.55×页宽 → 跨双列（全宽裁剪）；否则按图注中心点判断左/右列，只裁该列。代码见 `scripts/extract_figures.py` 的 `column_bounds`。

## 6. Write append 的 continuation_context 不匹配
- **现象**：用 `Write(append=true)` 续写时报 `40400 continuation_context mismatch`。
- **根因**：文件被前一次 Write 覆写后末尾已变，传入的旧上下文对不上。
- **对策**：改用 SearchReplace，以文件中**唯一锚点**（如某条脚注行 + 紧随的 `---`）定位，把"锚点"替换为"锚点 + 新内容"来追加。或先 Read 文件末尾取准确末 3 行再 append。

## 7. 图归属章节判断错误
- **现象**：把附录里的图（如 LATS Figure 3 实际在 Appendix C）放到正文 5.4，偏离原文结构。
- **根因**：未依据正文内容确认图的实际所在章节。
- **对策**：通读时记录每张图的图注所在页与所在章节；占位符插入到该图图注在原文出现的对应位置。

## 8. 无法直接查看图片时的核对
- **现象**：模型不能直接"看"裁出的 PNG，无法肉眼判断裁剪质量。
- **对策**：用像素尺寸做 sanity check——合理图区宽 150–2000px、高 80–2000px 且 < 整页尺寸；过高（≈整列/整页）=过裁，触发二次限定裁剪。裁剪后 grep 确认引用数 == 素材文件数。

## 9. 环境与依赖
- Python 包用 uv 管理：`uv run --with pymupdf python <script>`，无需在项目里装包、不污染环境。
- PDF 解析默认 PyMuPDF（fitz）；用户指定其他工具时从其指定。

## 10. 临时脚本清理
- 机械裁剪脚本运行完毕后，若不需要长期保留，从工作区删除，避免污染用户项目。skill 自带的 `scripts/extract_figures.py` 是长期复用工具，保留在 skill 目录内。
