## 职责分工（防重复、防漂移）

每个文件有唯一职责，**同一内容不在多个文件展开第二遍**；需要跨文件引用时给出文件名 + 小节号，引用是为了串联，不是替代正文：

- "是什么/为什么" → 00；"定了没" → 01；"模块怎么切" → 02；"数据长什么样" → 03；"人怎么操作" → 04；"用什么工具、怎么发出去" → 05；"先做什么后做什么" → 06；"会踩什么坑" → 07。

## 编号体系（全局唯一）

- **D-xx**：已定决策（Decided）。含结论、理由、出处。
- **U-xx**：未决问题（Undecided）。含问题描述、决策触发时机、候选方向。
- **R-xx**：预留字段/能力（Reserved）。数据结构已留位，实现延后。
- 同一决策原地迭代时复用旧编号并更新内容，禁止另起重复编号。新增编号接续现有最大号。

## 维护规则

- 更新旧文档前先通读该文件全文，避免漏更与自相矛盾。
- 架构级改动 = 先改文档（更新/新增编号）再改代码，见 `AGENTS.md` 的文档优先约定。
- 详略由文件性质决定，不因"别处写过"而在当前文件跳步或甩引用替代正文。
