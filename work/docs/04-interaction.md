## 1. v1 界面布局（D-30：三区域，其余全延后）

```
┌────────────────────────────────────────────┐
│  顶部极薄工具条：项目名 / 保存 / 导出 / 跑一步  │
├─────────────────────────────┬──────────────┤
│                             │  右侧单面板    │
│        中央画板（无限画布）    │  （选中对象的   │
│                             │   属性编辑 +   │
│                             │   未来的 agent │
│                             │   对话占位）    │
├─────────────────────────────┴──────────────┤
│  底部命令行：斜杠命令 + 命令历史回显            │
└────────────────────────────────────────────┘
```

北极星愿景（9 区域 15+ 面板：设计树/图层/正式与非正式列表/命令历史/调试/多终端/agent 对话/copilot/文件树/小窗多开…）完整保留在 backlog（U-10/U-12），但**面板间状态同步是指数级复杂度**，v1 严格不做第二个面板群。

## 2. v1 键位最小集（D-33）

| 操作 | 键位 | 备注 |
| --- | --- | --- |
| 选中 / 点选 | 左键 | Ctrl+点选 = 切换选择（U-14 最小集） |
| 框选 | 左键拖空白处 | 框选 = 加入当前选择；交/并集语义延后（U-14） |
| 平移画布 | 中键拖 / 空格+拖（可选） | |
| 缩放 | 滚轮 | 选中对象时滚轮缩放对象的备选交互延后 |
| 上下文菜单 | 右键 | 点在文本块上 = 文本菜单；点在画布上 = 画布菜单 |
| 重新布局 | 空格 | 只重算布局，不整理后端（D-32）；后端碎片整理 idle 静默做 |
| 删除 | Delete | 走 Command，可 undo；删被引用块先警告（case 11） |
| 撤销/重做 | Ctrl+Z / Ctrl+Shift+Z | Command 栈免费能力 |
| 保存 / 导出 | Ctrl+S / 工具条 | 导出 JSON 按钮必须显眼（D-41） |

明确不做（v2+）：Rhino 式"右键重复上一步"、右键+Ctrl 平行拖动、右键+Shift 缩放——需要精细命中测试与手势状态机，现在做会吃掉核心机制的工期。浏览器保留键（Ctrl+W/T/N/L、F12）拦不住，设计键位时避开（详见 07-risks §3）。

## 3. 抓块（promote）完整时序

这是产品的核心交互，逐帧定义：

```
① 用户在死文本块里编辑（纯 md，所见即所得）
② 框选块内一段文本（如 "Q"）
③ 触发抓取：底部命令行输入命令 或 右键菜单"抓为…" 或 快捷键
④ 浮出轻量确认 chip（悬浮在框选区上方）：
     [变量] [参数] [输入] [输出]
   - kind 猜测 = 开放词表里的高频项；端口方向猜测 = 位置意图（左→输入优先、右→输出优先），
     但仅作为默认高亮，不做全自动（D-31）
   - 回车 = 确认默认项；方向键 = 切换；Esc = 放弃
⑤ 确认 → 发 promote Command → Layer 2 建 FormalObject + Anchor 引用该文本（03 §4）
⑥ 对象按 kind 契约自动生成端口，画布上该文本段获得端口渲染（左右小圆点）与高亮边框
⑦ 文本本身保持原样：正式对象抓完依旧正式，周围非正式文本依旧非正式（D-15）
```

失败回退：chip 取消 → 零副作用；promote 校验失败（如跨块选择）→ 结构化错误提示，选择保留。

## 4. 连线与成环

- 从 out 端口拖到 in 端口；dtype 不匹配（四件套互斥）时禁止连接并提示。
- 新边成环 → 弹确认"这条边设为延迟边（delay）？"默认 yes（D-16，R-01）；拒绝则放弃该边。
- 悬空端口常态存在：渲染为灰色半圆，不报警（D-13）。

## 5. 手填值与状态可见性

- 右侧面板对选中对象提供 value 输入框；填入 = `setManualValue`，status → manual，下游闭包重算发 fresh（03 §5 S2）。
- status 的画布视觉编码（v1 约定）：

| status | 渲染 |
| --- | --- |
| fresh | 正常描边 + 值显示 |
| manual | 描边带手形小标记（区分于人填与算出） |
| undefined | 灰化 + 虚线描边 |
| error | 红描边，hover 显示 causedBy 链 |
| orphan | 黄底提示角标 |
| stale | （v1 自动求值下不出现，样式预留） |

## 6. 块与对象的一般操作

- 双击空白 = 新建 Block；Block 自由拖拽、缩放（rect）；z 序按叠放规则。
- 框选多个对象 → 右键"打组"：Group（视觉框，可穿透）或 Subgraph（封装，生成端口）二选一（D-10）。
- 自动排版 = 空格键触发布局算法重排当前视图（U-07 选型），**用户主动触发，绝不实时跟随**（否决清单）。
- gumball：v1 简化为选中对象的移动手柄 + 拖角缩放；完整 2D gumball 见 U-15。

## 7. 保存与安全感

- Ctrl+S 存 IndexedDB；状态栏显示"已保存/未保存"。
- 导出 JSON 快照按钮放在顶部工具条显眼位置（D-41：清浏览数据会连 IndexedDB 一起清，这是保命按钮）。
- 导入 JSON = 恢复快照（覆盖当前项目前弹确认）。

## 8. 命令行（底部）

v1 只做三件事：斜杠命令（`/save` `/export` `/layout` `/promote` 等对应 Command）、命令历史回显（只读列表）、错误信息显示。不做 shell、不做自然语言意图识别（那是 agent 面板的事，v2+，U-06）。
